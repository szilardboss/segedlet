 1. FELADAT: RSTP + ROOT BRIDGE (S1 kapcsoló)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Feladat: RSTP bekapcsolás, S1 legyen Root Bridge VLAN 1-en
         (legalacsonyabb prioritás)

MEGOLDÁS (TeraTerm / Cisco IOS):

  enable
  configure terminal

  ! RSTP mód beállítása:
  spanning-tree mode rapid-pvst

  ! Root Bridge beállítása VLAN 1-re (prioritás = 0 a legalacsonyabb):
  spanning-tree vlan 1 priority 0

  end
  write memory

ELLENŐRZÉS:
  show spanning-tree vlan 1

  → "This bridge is the root" sort kell látnod!
  → Bridge ID Priority: 1 (0 + 1 = VLAN ID hozzáadódik, szóval 1 lesz)
  → Mode: RSTP

MEGJEGYZÉS:
  ! Lehetséges prioritás értékek: 0, 4096, 8192, 16384...
  ! A 0 a legalacsonyabb = ez lesz a Root Bridge
  ! Alternatíva: spanning-tree vlan 1 root primary
    (ez automatikusan beállítja, de a priority 0 direktebb)

 2. FELADAT: OSPF DINAMIKUS FORGALOMIRÁNYÍTÁS (R1 és R2)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Feladat: OSPF Process ID 1, mindkét routeren, Area 0,
         közvetlenül csatlakozó hálózatok hirdetése

MEGOLDÁS - R1-en:

  enable
  configure terminal

  router ospf 1
   network <R1 hálózat1> <wildcard> area 0
   network <R1 hálózat2> <wildcard> area 0
   ! Minden közvetlenül csatlakozó hálózatot add hozzá!

  end
  write memory

MEGOLDÁS - R2-n (ugyanígy):

  enable
  configure terminal

  router ospf 1
   network <R2 hálózat1> <wildcard> area 0
   network <R2 hálózat2> <wildcard> area 0

  end
  write memory

PÉLDA ha pl. 192.168.50.0/24 és 10.0.0.0/30 hálózatok vannak:

  router ospf 1
   network 192.168.50.0 0.0.0.255 area 0
   network 10.0.0.0 0.0.0.3 area 0

WILDCARD GYORS:
  /24 → 0.0.0.255
  /30 → 0.0.0.3
  /16 → 0.0.255.255

ELLENŐRZÉS:
  show ip ospf neighbor          → szomszédok (FULL állapot kell!)
  show ip route ospf             → OSPF tanult útvonalak (O betűvel)
  show ip ospf                   → Process ID, Router ID

 3. FELADAT: VLAN 50 LÉTREHOZÁSA (S1 kapcsoló)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Feladat: VLAN 50 "Konyveles" névvel, F0/1 port access módban hozzárendelve

MEGOLDÁS:

  enable
  configure terminal

  ! VLAN létrehozása névvel:
  vlan 50
   name Konyveles
  exit

  ! Port hozzárendelése:
  interface FastEthernet0/1
   switchport mode access
   switchport access vlan 50
   no shutdown
  exit

  end
  write memory

ELLENŐRZÉS:
  show vlan brief
  → VLAN 50 "Konyveles" soránál az Fa0/1 port szerepel

  show interfaces FastEthernet0/1 switchport
  → Access Mode VLAN: 50 (Konyveles)

 4. FELADAT: ACL 10 HOZZÁFÉRÉSI LISTA (R1)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Feladat: Standard ACL 10, csak 192.168.50.10 engedélyezve,
         alkalmazás: VTY vonalak, bejövő (in) irány

MEGOLDÁS:

  enable
  configure terminal

  ! Standard ACL létrehozása:
  access-list 10 permit 192.168.50.10
  ! (az implicit deny any a végén automatikusan ott van)

  ! VTY vonalakra alkalmazás:
  line vty 0 4
   access-class 10 in
  exit

  end
  write memory

ELLENŐRZÉS:
  show access-lists
  → "Standard IP access list 10"
  →   10 permit 192.168.50.10

  show line vty 0 4
  → Inbound access list: 10

     VPC → Route Tables
     → Keresd meg a VállalatiVPC-hez tartozó route table-t
     → Routes fül → Edit routes → Add route

       Target: Internet Gateway → VállalatiIGW
     → Save changes

     → Subnet associations fül → Edit subnet associations
     → Pipáld be Subnet-1-et (ahol az EC2 lesz)
     → Save associations

  VPC → Your VPCs → VállalatiVPC legyen listában
  VPC → Subnets → 172.16.1.0/24 és 172.16.2.0/24 látható
  VPC → Internet Gateways → State: attached
  Route Table → Routes: 0.0.0.0/0 → igw-xxxxxxxx
