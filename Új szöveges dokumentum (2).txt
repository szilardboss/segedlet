1. FELADAT: RSTP + ROOT BRIDGE (S1 kapcsoló) 
 
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ 
 
Feladat: RSTP bekapcsolás, S1 legyen Root Bridge VLAN 1-en 
 
         (legalacsonyabb prioritás) 
 
 
 
MEGOLDÁS (TeraTerm / Cisco IOS): 
 
 
 
  enable 
 
  configure terminal 
 
 
 
  ! RSTP mód beállítása: 
 
  spanning-tree mode rapid-pvst 
 
 
 
  ! Root Bridge beállítása VLAN 1-re (prioritás = 0 a legalacsonyabb): 
 
  spanning-tree vlan 1 priority 0 
 
 
 
  end 
 
  write memory 
 
 
 
ELLENŐRZÉS: 
 
  show spanning-tree vlan 1 
 
 
 
  → "This bridge is the root" sort kell látnod! 
 
  → Bridge ID Priority: 1 (0 + 1 = VLAN ID hozzáadódik, szóval 1 lesz) 
 
  → Mode: RSTP 
 
 
 
MEGJEGYZÉS: 
 
  ! Lehetséges prioritás értékek: 0, 4096, 8192, 16384... 
 
  ! A 0 a legalacsonyabb = ez lesz a Root Bridge 
 
  ! Alternatíva: spanning-tree vlan 1 root primary 
 
    (ez automatikusan beállítja, de a priority 0 direktebb)

GYAKORI HIBÁK ÉS MEGOLDÁSUK

    → Vagy utólag: Elastic IP lefoglalása + hozzárendelés 
 
 
 
  ✗ Nem érhető el a webszerver (HTTP 80) 
 
    → Security Group → Inbound rules → HTTP 80 engedélyezve van-e? 
 
    → Source: 0.0.0.0/0 legyen! 
 
 
 
  ✗ Subnet nem kap internet elérést 
 
    → Route Table-ben van-e 0.0.0.0/0 → IGW szabály? 
 
    → A subnet hozzá van-e rendelve a Route Table-hez? 
 
 
 
  ✗ IGW "detached" állapotban 
 
    → Internet Gateways → Actions → Attach to VPC 
 
 
 
  ✗ DB szerver nem érhető el MySQL-en 
 
    → Security Group: 3306-os port nyitva? 
 
    → Source: pontosan a web szerver PRIVÁT IP-je /32-vel? 
 
 
 
  ✗ Wrong CIDR - subnet nem fér bele a VPC-be 
 
    → VPC: 10.0.0.0/16 → Subnet max: 10.0.x.x/24 (belül kell legyen!) 
 
    → pl. 10.100.0.0/16-os VPC-be: 10.100.1.0/24 subnet fér
